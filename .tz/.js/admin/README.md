# RJF Admin Panel — সেটআপ গাইড

এই এডমিন প্যানেলটা আপনার মূল ওয়েবসাইটের `admin/` ফোল্ডারে বসানো হয়েছে এবং একই Firebase প্রজেক্ট
(`member-selection`) ব্যবহার করে। কোনো আলাদা হোস্টিং/সার্ভার লাগবে না — যেভাবে বাকি সাইট হোস্ট করা আছে
সেভাবেই `admin/` ফোল্ডারটাও আপলোড করে দিলেই কাজ করবে।

## ১) Firebase Console-এ যা করতে হবে

### ক) Email/Password Authentication চালু করুন
1. Firebase Console → আপনার `member-selection` প্রজেক্ট → **Authentication** → **Sign-in method**
2. **Email/Password** চালু (Enable) করুন
3. **Users** ট্যাবে গিয়ে **Add user** — নিজের এডমিন ইমেইল ও পাসওয়ার্ড দিয়ে একটা ইউজার তৈরি করুন
   (যেমন: `imran.info.me@gmail.com`)

### খ) Firestore Security Rules আপডেট করুন
প্রজেক্টের রুটে থাকা `firestore.rules` ফাইলের পুরো কন্টেন্ট কপি করে Firebase Console →
**Firestore Database** → **Rules** ট্যাবে পেস্ট করে **Publish** করুন।

⚠️ **এইটা বাদ দিলে এডমিন প্যানেলের এডিট/ডিলিট বাটন কাজ করবে না (Permission denied error দিবে)।**

### গ) এডমিন ইমেইল মিলিয়ে নিন
নিচের দুই জায়গায় একই ইমেইল থাকতে হবে:
- `admin/js/admin-config.js` → `ADMIN_EMAILS` অ্যারে
- `firestore.rules` → `isAdmin()` ফাংশনের ভিতরের লিস্ট

একাধিক এডমিন রাখতে চাইলে দুই জায়গাতেই ইমেইল যোগ করুন এবং rules আবার Publish করুন।

## ২) ব্যবহার

- এডমিন প্যানেলে ঢুকতে যান: `yoursite.com/admin/login.html`
- লগইন করলে ড্যাশবোর্ডে চলে যাবেন

### আবেদন / সদস্য ফরম
যারা `#/apply` পেজ থেকে ফরম সাবমিট করেছেন তাদের সবার তালিকা এখানে দেখা যাবে (মোট কতজন, কে কে —
রিয়েল-টাইমে আপডেট হয়)। প্রতিটা আবেদনে ক্লিক করে:
- সব তথ্য এডিট করা যাবে
- **Profile ছবির লিংক (photo_url)** বসানো যাবে — এইটা বসালে `verify.html`-এ QR/ID দিয়ে যাচাই করার
  সময় ওই ছবিটাই দেখাবে
- **স্ট্যাটাস** পরিবর্তন করা যাবে: পেন্ডিং / অনুমোদিত / **ব্লকড** — কাউকে ব্লক করলে তার সদস্য আইডি
  দিয়ে আর `verify.html`-এ ভেরিফাই করা যাবে না ("সদস্য আইডি নিষ্ক্রিয় করা হয়েছে" দেখাবে)
- ভেরিফিকেশন লিংক কপি করার বাটন আছে
- CSV এক্সপোর্ট করা যাবে

### কমিটি সদস্য / দাতাগণ
সাইটের `#/member` ও `#/donors` পেজে যে তালিকা দেখানো হয়, সেটাও এখন এখান থেকে ম্যানেজ করা যাবে
(যোগ/এডিট/ডিলিট) — কোনো কোড পরিবর্তনের দরকার নেই। এখানে কোনো ডাটা যোগ করলে সেটাই সাইটে
প্রায়োরিটি পাবে (Firestore-এ কিছু না থাকলে ফাইলে থাকা ডিফল্ট তালিকা দেখাবে, তাই এখনই সব ভাঙার
কোনো ঝুঁকি নেই)।

## ৩) নিরাপত্তা সম্পর্কে গুরুত্বপূর্ণ কথা

- এডমিন প্যানেলের লগইন পেজ শুধু UI সুরক্ষা — আসল সুরক্ষা `firestore.rules`-এ। তাই ধাপ ১(খ) অবশ্যই
  করতে হবে।
- `apiKey` কোডে দেখা গেলেও এটা কোনো নিরাপত্তা ঝুঁকি না (Firebase-এর ক্ষেত্রে এটাই স্বাভাবিক) — আসল
  সুরক্ষা নিয়ন্ত্রণ হয় Security Rules দিয়ে।
- এডমিন পাসওয়ার্ড শক্তিশালী রাখুন এবং কারও সাথে শেয়ার করবেন না।

## ৪) ভবিষ্যতে যা যোগ করা যাবে (এখনো বাকি)

Gallery ও Hero/About সেকশনের কনটেন্ট এখনো স্ট্যাটিক ফাইলে আছে (`js/gallery-data.js`, `js/data.js`) —
এগুলো চাইলে একই প্যাটার্নে পরে Firestore-চালিত করে এডমিন প্যানেলে যোগ করে দেওয়া যাবে।
